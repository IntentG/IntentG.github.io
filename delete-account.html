Запрос удаления игрового аккаунта и данных

На этой странице можно начать запрос через поддержку без установки игры. Запросы требуют проверки принадлежности аккаунта. В закрытой тестовой версии удаление доступно на экране входа после авторизации и отдельного подтверждения. Эта веб-страница помогает составить обращение в поддержку; открытие ссылки не удаляет данные.

Как отправить запрос

Напишите на Sublustrum123@gmail.com с темой «RivenShifters — удаление аккаунта и данных». Укажите, что хотите удалить игровой аккаунт и связанный прогресс. Если знаете свой ID игрока, его можно добавить, но установка или повторная установка игры для отправки запроса не требуется.

Для аккаунтов с подтверждённой почтой поддержка отправит на заранее привязанный адрес отдельное письмо RivenShifters с номером запроса и одноразовым кодом удаления. Ответьте в переписке поддержки, указав этот номер и код, только если действительно хотите удалить соответствующий игровой аккаунт. Код действует 10 минут; если он истёк, запросите новое письмо у поддержки — устанавливать игру для этого не нужно. Один ID или совпадающий адрес отправителя не являются доказательством владения. Никогда не присылайте пароли, токены входа, платёжные данные или коды входа Google и Unity.

Ссылка открывает черновик письма; письмо необходимо отправить самостоятельно. Если почтовое приложение не открывается, скопируйте адрес в используемую почту. Открытие страницы или черновика не означает, что запрос отправлен или данные уже удалены.

Однократное подтверждение почты

Начиная с версии 201 закрытого теста новые игроки подтверждают доступную им почту один раз перед первой игрой. При обычных последующих входах повторный почтовый код не нужен. Этот адрес используется для подтверждения удаления игрового аккаунта без установленной игры; рекламные рассылки на него не отправляются.

Если аккаунт создан в более ранней внутренней тестовой версии либо доступ к подтверждённой почте утрачен, всё равно можно обратиться в поддержку с этой страницы. Опишите ситуацию: потребуется отдельная проверка принадлежности. Не устанавливайте игру только для отправки обращения. Удаление не выполняется по одному присланному ID или неподтверждённому адресу.

Обращения обрабатываются вручную. Поддержка сообщит ожидаемый срок выполнения после получения запроса. Окончательное удаление подтверждается отдельным ответом; отправка письма или кода сама по себе ещё не означает завершение.

Какие данные относятся к запросу

Игровой аккаунт RivenShifters, облачный игровой прогресс (предметы, улучшения, валюта, экипировка, задания, достижения, история рейдов) и привязанный адрес почты, а также связанные с аккаунтом служебные записи игры с учётом описанных ниже сроков хранения. Общий Unity Player Account, используемый в других играх, не является аккаунтом только RivenShifters и не удаляется этим запросом.

После завершённого удаления восстановить игровой прогресс нельзя. Удаление приложения само по себе не удаляет облачные данные. Локальные копии на других устройствах и резервные копии Android требуют отдельного внимания: письмо не может физически стереть данные с отключённого телефона.

Удаление в тестовой версии

Перезапустите игру, войдите и до нажатия «Играть» выберите «Удалить игровой аккаунт». Прочитайте предупреждение и подтвердите удаление. При обрыве связи повторный запуск продолжит сохранённый запрос. Успешное завершение удаляет игровой аккаунт Unity Authentication, облачный прогресс и локальное сохранение на этом устройстве. Общий Unity Player Account остаётся доступен для других игр и повторного входа; повторный вход создаёт новый игровой профиль без удалённого прогресса.

Срок хранения

Облачный игровой прогресс хранится до запроса удаления, без автоматического удаления за неактивность. Переписка поддержки, включая вложения, хранится отдельно — 3 месяца с момента решения обращения. Это не обещание хранить игровой профиль ещё 3 месяца после удаления.

Общий Unity Player Account

Unity Player Accounts использует email для создания аккаунта и отдельный идентификатор пользователя. Этот общий аккаунт может использоваться в других играх. Политика конфиденциальности Unity.

Управлять удалением общего Unity Player Account. Запросы о доступе к данным и конфиденциальности этого аккаунта направляйте непосредственно Unity: unity-player-login-privacy@unity3d.com.

Это отдельный процесс: удаление общего Unity Player Account не удаляет автоматически данные RivenShifters, а запрос IntentGames не удаляет общий аккаунт Unity. Запрос удаления игрового профиля RivenShifters требует проверки принадлежности; в закрытой тестовой версии доступно удаление игрового аккаунта после входа и отдельного подтверждения. При невозможности автоматического удаления требуется проверка поддержки. Открытие любой ссылки само по себе ничего не удаляет.

Минимальная запись об удалении

После подтверждённого удаления игрового аккаунта сохраняется минимальная служебная запись: идентификатор удалённого игрового профиля, статус и время завершения операции, технические идентификаторы и защитные хеши. Инвентарь и игровой прогресс в неё не входят. Она нужна для подтверждения удаления, защиты от повторного применения старых запросов и разбора сбоев.

Срок хранения этой записи — 365 дней после проверенного завершения удаления, затем выполняется проверка и очистка. При незавершённом споре или обнаруженной ошибке запись может быть временно удержана до разрешения ситуации; ответственный оператор пересматривает такие случаи каждые 30 дней. Журнал действий поддержки хранится отдельно 365 дней с момента действия. Эти сроки не устанавливают срок хранения финансовых документов; покупки в первом закрытом тесте отключены.
